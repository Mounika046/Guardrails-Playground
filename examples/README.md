# Playground Examples

These files give quick test material for the customization features in the app.
They are not loaded automatically.

Use them like this:

- copy regex rule values into the regex customization form
- copy LLM prompt examples into the LLM customization fields
- upload embedding reference files through the embeddings customization panel
- copy runtime inputs into the app textarea

Folders are grouped by safety mechanism:

```text
content_moderation/
pii_detection/
prompt_injection_detection/
```
